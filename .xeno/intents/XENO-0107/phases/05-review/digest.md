The risk worth carrying forward is that a refusal is louder than a red verdict: it stops
a pipeline rather than recording a failure in it, and a project with a flaky external
gate will read that as Xeno breaking. The error names the gate and nothing else
mitigates it, which is a real limit to note before WP4 brings the first external gate
rather than after.
