The decision is the second of #97's two readings: an adapter returns requirements and Compare keeps only
the waive logic, the declared-or-not filter, and section 13's unchecked merge_method line. What rejects the
first reading is allow_bypass, where GitHub answers with enforce_admins and GitLab with three lists of
grants — reducing those to a boolean is a judgement about one host's access levels, and the rejected reading
has to put it either in the package meant to know no host or in a field shaped like GitLab's answer.
approvals.not_by_author rejects it again, since it is met by construction on one host and a settable thing on
the other, so the two differ in which states exist. The names stay enumerated in the domain, which is the
line that keeps this from being a licence; the cost is that #99's table is partly undone in the same release.
