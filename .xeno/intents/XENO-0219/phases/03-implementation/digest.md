`internal/git` is one function and the only subprocess in the tree: `git log --reverse` over the range,
returning hash, signature letter, parent count, author, subject and trailers, with `Signed` applying
A70, `HasTrailer` comparing a key case insensitively and never the value, and an empty end of the range
an error rather than a default. The separators are the ASCII unit and record separators, not NUL,
because an argument containing NUL is rejected by exec before git runs with a message that names
nothing — the first version did exactly that. `internal/gates`'s package comment is replaced to name
what the prohibition protects, `Ctx` carries `Base` and `Head`, and the runner passes them. The registry
has its five entries and an `eval` loads the range once per gate run, so five commit rules read one
`git log`. The five: the section implication with an empty antecedent green and an unknown section a
configuration error; every subject against a named shipped pattern; a trailer's key on every commit; a
signature that verifies; and every decision's `by` against the authors of the range, with no decisions
green. `conventional-commits-with-issue` ships beside the pattern that was there. Six deviations, two
of them failures in fixtures rather than in the subject, and #160's unimplemented-type test rewritten
to name a type no specification lists.
